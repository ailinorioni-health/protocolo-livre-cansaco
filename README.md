# Protocolo Livre do Cansaço 7D — App

App de acompanhamento do Protocolo Livre do Cansaço 7D.

## Para rodar localmente

```bash
npm install
npm run dev
```

## Para fazer build

```bash
npm run build
```

## Código de acesso

Definido no arquivo `src/App.jsx`, linha 5:

```js
const ACCESS_CODE = 'livre7d';
```

Para mudar, edite essa linha e faça novo deploy.

## Tecnologias

- React 18
- Vite (bundler)
- localStorage (persistência local no navegador)
